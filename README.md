# Radiance by Deepika - Beauty Parlour Website

A modern, responsive web application for Radiance Beauty Parlour, located in Medininagar (Daltonganj). This project serves as the digital front door for the business, showcasing its facilities and streamlining client bookings.

## 🌟 Features
- **Mobile-First Architecture:** Tailored specifically for mobile viewports, featuring touch-optimized layouts without desktop-specific hover effects to ensure a flawless mobile experience.
- **Ambiance & Service Showcase:** Highlights the parlour's aesthetic, including the signature green turf wall, neon signage, and modern styling stations.
- **Booking Integration:** Features quick-access contact details and QR codes for easy appointment scheduling.

## 🛠️ Technologies Used
- **Frontend:** React (JSX), JavaScript, CSS
- **Deployment:** Render (`radiance-beauty-parlour_dto`)

## 🚀 Getting Started

### Prerequisites
Make sure you have Node.js and npm installed on your local machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/31-nav/radiance-beauty-parlour.git
   ```
2. Navigate to the project directory:
   ```bash
   cd radiance-beauty-parlour
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Development Server
Run the following command to start the application locally:
```bash
npm run dev
# or
npm start
```
Open your local host address in your browser to view the application.

## 📦 Deployment
This project is integrated and configured for deployment via Render. Ensure your dashboard settings point to the correct build command and publish directory to avoid build failures.
